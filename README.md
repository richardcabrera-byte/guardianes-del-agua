# guardianes-del-agua
“Guardianes del Agua” es un juego de Ciencias Naturales para 4.º de EGB. Promueve el cuidado responsable del agua mediante preguntas y retos. Aplica el DUA con texto, íconos, audio, respuestas por selección u oralmente, niveles, retroalimentación y opciones de letra grande, alto contraste y más tiempo.
